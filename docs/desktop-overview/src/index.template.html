Product overview

Bike4Mind, on your machine.

A desktop app that gives Bike4Mind hands: it works in your repositories, runs your commands, drives a real browser, and still makes images and audio the way the web app does.

Why a desktop app when there is already a web app?

The Bike4Mind web app is excellent for conversation, knowledge and collaboration. A browser tab, by design, cannot touch your computer. The desktop app exists for the work that lives there.

Bike4Mind web app

  • Lives in a browser tab, sandboxed from your machine
  • Cannot read your project folders or run your build
  • Cannot use a browser as a tool on your behalf
  • Best for chat, knowledge, notebooks and team sharing

Bike4Mind Desktop

  • Runs on your machine, in the folders you grant it
  • Reads and edits files, runs shell commands and dev servers
  • Owns a built-in browser the agent can drive
  • Same account, same models, same credits, same backend

Features

Two modes in one window. Chat for general work, Code for work grounded in a repository.

Code sessions

An agent grounded in your repo

Pick a project folder and start. The agent searches, reads, edits and tests inside it, and every conversation groups under its project in the sidebar.

  • Workspace bar: shows the project and branch the agent is working in. Change them any time. Tick worktree to give the session its own copy of the branch, so parallel tasks never collide.
  • Real tools: file read and write, patching, glob and grep, shell commands, and long-running background processes with live output.
  • Plans, questions and diffs: the agent keeps a todo list, asks multiple-choice questions when it needs a decision, and shows edits as diffs.
  • Skill-aware: finds your project and personal skills and lists them in a / picker. The agent can use them too. Project skills load only after you trust the project.
  • Memory-aware: each project keeps its own memory, loaded from the first message. The agent saves what is worth keeping and deletes what is wrong, and you review each change. Memory lasts across sessions.
  • Extend it with MCP servers for your own tools.
Agent-to-agent

Sessions that start sessions, and talk to each other

An agent can hand work to another agent. A session can start a child session for a self-contained job, such as an independent PR review, and keep talking to it afterwards. Every message is an explicit tool call you can see in the transcript.

session_spawn

Starts a child with an empty conversation, so the brief has to carry the whole task. You approve every spawn first, and the child can only touch the folders its parent can. It gets its own worktree, so it never edits the parent's files.

Told, not handed back

The parent keeps working. When the child finishes it learns that it finished, and pulls the content with session_read when it needs it.

session_send

Follow up with a child that already exists instead of starting over. You approve every send too. The receiver sees it as a message from another session, not from you, and weighs it that way.

Built-in browser

A real browser, side by side with the conversation

Each conversation gets its own browser pane. You can use it like any browser, and the agent can use it too. It keeps its own cookie jar, separate from everything you browse.

Use it for end-to-end testing

Start your dev server, then ask the agent to test the flow. It opens your local app, fills the form, clicks through, reads the page and reports pass or fail for each case, with screenshots.

  • Catches regressions the unit tests do not see
  • Test what you just changed, right after changing it
  • The same session that wrote the fix can verify it

Bring your Chrome sign-ins along

Sites behind SSO and 2FA stop an agent cold. Import cookies from your own Chrome profile, per site, and the built-in browser is signed in already.

  • You choose the sites from a list of your own Chrome cookies. The page and the model can never name one for you.
  • Only chosen sites are read. The rest of your Chrome cookies are never decrypted.
  • Never in the transcript. The import is a click, not a tool, and only counts and hostnames cross into the UI.
  • Manage or remove imported sites any time from the same menu.

Use it to automate websites

Anything you would do by clicking, the agent can do: open a site, read what is on it, extract the parts you care about, fill forms and move between pages.

  • Pull headlines, prices, or table data into a list
  • Walk repetitive admin screens
  • Watch it happen in the pane, and take over whenever you like

What Bike4Mind Desktop adds beyond Claude Desktop

Claude Desktop is a general assistant. Bike4Mind Desktop is a client for the whole Bike4Mind platform, so the creative and knowledge tools of the web app come with it, and more of them arrive as they are ported over.

Image generation

Make images in the conversation

Describe it and the agent calls generate_image. The result appears inline and is saved to disk for the session.

  • Posters, diagrams, mockups, thumbnails
  • Refine in follow-up messages without leaving the thread
  • Metered against your Bike4Mind credits
Audio generation

Voice, music and sound effects

Three tools cover the audio the web app can make, each with a built-in player in the thread, and a browsable copy can be kept in your Bike4Mind files.

generate_speechgenerate_musicgenerate_sound_effect
  • Narrate an announcement or a script
  • Score a short jingle
  • Drop in a one-second effect

And everything else on the web side that makes sense locally

The desktop app is built on the same backend and shared schemas as the web app, so porting a capability is a matter of giving it a native surface. Already here today:

  • Artifacts rendered in the app, with a library to find them again
  • Model picker and reasoning effort for every conversation, with live credit and context meters
  • MCP servers and skills for connecting your own tools and workflows
  • Attachments by drag and drop, prompt suggestions, a message queue, and light and dark themes
  • Built-in updates and installers for macOS and Windows
