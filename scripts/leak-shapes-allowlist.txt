# # comments skipped. A content hit is dropped when a pattern matches "<path>:<line>", a path

#
# Every entry carries a comment saying why the match is legitimate. Prefer the narrowest
# pattern that covers the case: a path for a fixture file, "path:" plus a fragment for one
# line in a source file.
